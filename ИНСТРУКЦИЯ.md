# Access-Наставник — инструкция

## 1. Как открыть
1. **Через интернет (проще всего):** https://fandex01337-hash.github.io/access-nastavnik/ — работает на компьютере и телефоне, разрешение на микрофон браузер запомнит.
   Без интернета: дважды щёлкните **`Запустить.bat`** — бот откроется по адресу http://localhost:8765 (окно с сервером не закрывайте, пока работаете).
2. Лучший браузер — **Microsoft Edge** (голоса Svetlana, Dariya, Aigul) или **Google Chrome**. В Firefox распознавания речи нет.
3. Щёлкните в любом месте страницы — бот поздоровается голосом.

Без ключей всё работает: бесплатный голос браузера и встроенная база (63 темы, тесты, практикум).

## Голос
- 🎤 — задать один вопрос голосом (или **Ctrl+M**).
- «🎙 Поговорить голосом» — разговор без клавиатуры: после каждого ответа микрофон включается сам.
- Команды: «стоп», «повтори», «продолжи», «громче», «тише», «открой запросы», «начни тест», «ответ Б», «дальше», «покажи результаты», «выключи микрофон».
- Бот понимает термины на слух: «д лукап» → DLookup, «хэвинг» → HAVING, «ду кмд» → DoCmd и т. п.

## Тесты и результаты
- **📝 Тест: таблицы, формы, отчёты** — 10 вопросов среднего уровня (4 + 3 + 3, каждый раз новый набор). **✅ Общий тест** — 10 вопросов по всем темам.
- Перед тестом ученик вводит фамилию, имя и группу. Правильный ответ и пояснение видны **только после ответа**, подсказки во время теста не выдаются.
- После каждого вопроса показан счёт «Верно: X из N», в конце — правильные ответы, процент, оценка и разбор ошибок.
- **📋 Результаты** — список всех прошедших: имя, группа, тест, баллы, оценка, дата. Сортировка «по баллам», кнопка «Скачать для Excel».
- Список хранится в браузере **на этом компьютере**. Если ученики проходят тест на разных компьютерах, соберите файлы Excel с каждого.

## Группы (рандомайзер)
- «🎲 Группы» в меню или кнопка «🎲 Разделить на группы» внизу (голосом — «раздели на группы»).
- Список студентов можно править прямо в окне — по одному человеку в строке. Изменения сохраняются в браузере, «↺ Исходный список» возвращает список группы.
- Поля «🔗 Всегда вместе» и «🚫 Всегда в разных группах» — пары через «+», по одной в строке (можно писать только имя, если оно не повторяется). Эти условия видны на экране и под результатом.
- Выберите число групп (2–6) и нажмите «🎲 Разделить»: деление случайное, размеры групп отличаются не больше чем на одного человека.
- «Копировать» и «Скачать для Excel» — чтобы отправить группы студентам.

## 2. Реалистичный голос (кнопка ⚙️)
Если ключ неверный или сервис недоступен, бот сам вернётся к бесплатному голосу.

**Azure (рекомендуется)**
1. portal.azure.com → «Создать ресурс» → **Speech / Службы речи**, бесплатный тариф F0.
2. «Ключи и конечная точка» → скопируйте **Ключ 1** и **Регион** (например, `westeurope`).
3. В боте: ⚙️ → «Б) Реалистичный» → Azure → вставьте ключ и регион → «Сохранить и проверить голос».

**Yandex SpeechKit**
1. console.yandex.cloud → сервисный аккаунт с ролью `ai.speechkit-tts.user` → создайте **API-ключ**.
2. Yandex не принимает запросы прямо из браузера, поэтому нужен маленький прокси. Сохраните как `proxy.js` и запустите командой `node proxy.js` (нужен Node 18+):
   ```js
   const http = require('http');
   http.createServer(async (req, res) => {
     res.setHeader('Access-Control-Allow-Origin', '*');
     res.setHeader('Access-Control-Allow-Headers', 'Authorization, Content-Type');
     if (req.method === 'OPTIONS') return res.end();
     let body = ''; for await (const c of req) body += c;
     const r = await fetch('https://tts.api.cloud.yandex.net/speech/v1/tts:synthesize', {
       method: 'POST',
       headers: { Authorization: req.headers.authorization || 'Api-Key ' + process.env.YA_KEY,
                  'Content-Type': 'application/x-www-form-urlencoded' },
       body
     });
     res.writeHead(r.status, { 'Content-Type': 'audio/mpeg' });
     res.end(Buffer.from(await r.arrayBuffer()));
   }).listen(8787);
   ```
3. В боте: ⚙️ → «Б) Реалистичный» → Yandex → ключ и адрес прокси `http://localhost:8787`.

**ElevenLabs** — ключ в профиле (API Keys), ID женского голоса — в библиотеке голосов.

## 3. Ответы ИИ (необязательно)
⚙️ → «Ответы ИИ» → Anthropic Claude или OpenAI-совместимый API → вставьте ключ. Тогда бот отвечает на любые вопросы по Access, в том числе на казахском. Ключи хранятся в браузере, а не в файле.

## 4. Как добавить свой вопрос
Откройте `index.html` в Блокноте, найдите строку `<script type="text/plain" id="kb">` и добавьте блок по образцу:

~~~
@@ queries | Название темы
keys: ключевые слова, синонимы, как спрашивают студенты
Короткое объяснение.
### Шаги
1. **Создание → Конструктор запросов**.
2. Следующий шаг.
```sql
SELECT Фамилия FROM Студенты;
```
> Совет.
??? Текст мини-задания.
~~~

Разделы: `tables`, `queries`, `forms`, `reports`, `macros`, `vba`, `extra`. Сохраните файл и обновите страницу.

Вопросы общего теста — массив `QUIZ`, теста по таблицам, формам и отчётам — `QUIZ_TFR` (поле `t` — тема, `a` — номер правильного варианта, 0 = первый). Задания практикума — массив `PRACTICE`.
