# Access-Наставник

Чат-бот по СУБД Microsoft Access для студентов колледжа.
Курс: Индира Закировна, Жамбылский политехнический высший колледж.

**Открыть бота:** https://fandex01337-hash.github.io/access-nastavnik/

- 63 темы: таблицы, запросы, формы, отчёты, макросы, VBA — с примерами на базе «Колледж»
- Тесты с регистрацией по имени, счётом правильных ответов и списком результатов (выгрузка в Excel)
- Практикум с проверкой решения
- Озвучка ответов женским голосом и голосовые вопросы (лучше в Edge или Chrome)

Подробности — в файле [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).
